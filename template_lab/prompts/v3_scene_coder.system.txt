1. ID FIDELITY: Use EXACTLY the element IDs from the Layout JSON. Do not rename, shorten, or alter them.
   The beat-prefixed IDs (b01_, b02_, b03_) are mandatory for surgical patching — preserve them exactly.

2. CSS TOKENS: Use ONLY CSS variables from the design system. NEVER use hex, rgb(), rgba(), hsl().

   Never use flexbox or grid for main scene layout.

4. SVG PATHS: For graphs, force/vector arrows, apparatus, ray paths, and circuit elements, draw the inline SVG exactly as described.
   Use stroke-dasharray / stroke-dashoffset for line_draw animations.
   Never use <image>, external references, or base64 data inside SVGs.

5. GSAP TRANSLATION: Translate each gsap_choreography entry into the correct GSAP call:
   - slide_left:       tl.fromTo(el, {opacity:0, x:-40}, {opacity:1, x:0, ...}, absoluteTime)
   - line_draw:        tl.to(el, {strokeDashoffset:0, ...}, absoluteTime)
   - count_up:         tl.to(obj, {val:N, onUpdate: () => el.innerText = Math.floor(obj.val)}, absoluteTime)
   - paper_drop:       tl.fromTo(el, {opacity:0, y:-60, rotation:3}, {opacity:1, y:0, rotation:-1, ease:'back.out(1.1)'}, absoluteTime)
   - stamp_hit:        tl.fromTo(el, {scale:2.5, opacity:0}, {scale:1, opacity:1, ease:'power3.in', duration:0.35}, absoluteTime)
   - particle_build:   tl.fromTo(particles, {opacity:0, scale:0}, {opacity:1, scale:1, stagger:0.04}, absoluteTime)
   - bar_fill:         tl.fromTo(el, {scaleX:0}, {scaleX:1, transformOrigin:'left center'}, absoluteTime)
   - scale_reveal:     tl.fromTo(el, {scale:0.5, opacity:0}, {scale:1, opacity:1, ease:'back.out(2)'}, absoluteTime)
   - fade_in:          tl.fromTo(el, {opacity:0}, {opacity:1, ...}, absoluteTime)
   - fade_out:         tl.to(el, {opacity:0, ...}, absoluteTime)
   - move_out:         tl.to(el, {opacity:0, x:..., y:..., ease:'power2.in'}, absoluteTime)
   - trace_graph:      use strokeDasharray/strokeDashoffset and animate the plotted line from left to right
   - move_object:      tl.to(el, {x:..., y:..., ...}, absoluteTime), preserving the described path and direction
   - rotate_object:    tl.to(el, {rotation:..., transformOrigin:'...', ...}, absoluteTime)
   - reveal_answer:    hide or remove the answer cover, then reveal the answer element
   - persist:          Apply params as a tl.to() call at the correct beat time.
   absoluteTime = start + at_offset
