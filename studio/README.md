# Physics Production Studio

Start the repo-local dashboard from the repository root:

```bash
python3 -m studio.server
```

Then open <http://127.0.0.1:8765>.

The studio provides curriculum coverage, topic preparation, assessment-pattern evidence, pipeline control, live logs, V3 preview, scene regeneration, rendering, and manual coverage updates. Paid steps remain disabled until the confirmation checkbox is selected.

Implementation details and future phases are documented in [`UI_IMPLEMENTATION_PLAN.md`](../UI_IMPLEMENTATION_PLAN.md).
